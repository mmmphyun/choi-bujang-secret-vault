탈환 작전실

판정기 규칙·탐지 사건·회수 상태·복구 버전 및 1~11단계 방어 실측 결과를 확인합니다. 화면의 성공 문구만으로 통과를 증명하지 않으며, 실제 API 응답과 미실행을 엄격히 구분합니다.

탈환 작전실 현황 요약

1. 판정기 규칙

활성 규칙 수: 3개

규칙 목록: device_registered, step_up_required, zone_policy

엔진 연동: ALEPH SDP Engine

2. 탐지 사건 요약

감시 규칙: burst_read

탐지 기준: 10분 내 120건 초과 (121건 이상)

감시 상태: 정상 감시 중 (monitoring)

3. 회수 상태

조치 제안: propose_revocation

제안된 회수: 0건

최근 처리: observe (정상 관찰)

4. 복구 버전

안전 정책 버전: v1.0.0

무결성 대조: SHA-256 일치 확인

복구 엔드포인트: POST /api/notes/restore

※ 가상 메모 본문은 작전실 요약 정보에 포함되지 않으며 실제 서버 응답 메타데이터만을 읽어와 표시합니다.
